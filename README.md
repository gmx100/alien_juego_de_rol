# Habilidades en ALIEN: El Juego de Rol (Free League Publishing)

En el juego de rol de **ALIEN**, las habilidades (*Skills*) son las herramientas fundamentales para sobrevivir. El sistema utiliza el **Year Zero Engine**, donde las habilidades están vinculadas a cuatro atributos principales.

## 🛠️ Mecánicas Fundamentales

### El Grupo de Dados
Para realizar una acción, se suman los puntos del **Atributo** + la **Habilidad** correspondiente. El total es el número de dados de seis caras ($d6$) que lanzarás.
* **Éxito:** Solo necesitas un **6** en cualquiera de los dados.
* **Múltiples Éxitos:** Los "6" adicionales permiten comprar efectos especiales o mejorar la calidad de la acción.

### El Factor Estrés
ALIEN introduce una mecánica única de tensión:
1.  **Dados de Estrés:** A medida que la situación se vuelve peligrosa, sumas dados de color diferente a tu reserva.
2.  **Adrenalina:** Estos dados aumentan tu probabilidad de éxito (representan el instinto de supervivencia).
3.  **Pánico:** Si sacas un **1** en un dado de estrés (un símbolo de "Facehugger"), tu personaje debe realizar una tirada en la **Tabla de Pánico**.

---

> ⚠️ **Nota del Director:** En el espacio, nadie puede oír tus gritos, pero todos pueden ver cómo fallas una tirada de *Observación* justo antes de que el Xenomorfo salte del conducto de ventilación.

## 🚀 Especialización por Carrera
Cada personaje tiene una **Carrera** (Marine Colonial, Científico, Piloto, etc.) que le otorga:
* Una **Habilidad Clave** (donde puede empezar con más puntos).
* Acceso a **Talentos** exclusivos que modifican el uso de estas habilidades.

### 🌟 Talentos Generales (Para todos)

Estos talentos no dependen de tu profesión y representan entrenamiento básico:

* **Puntería Fina (*Sharp Shooter*):** +2 al disparar con armas de precisión (rifles).
* **Reflejos de Combate (*Combat Reflexes*):** Puedes re-tirar tu iniciativa al principio de un combate.
* **Mente Fría (*Cool Head*):** Ganas un +2 en las tiradas de Pánico para mantener el control.
* **Sanitario (*Medic*):** Ganas un +2 en las tiradas de *Primeros Auxilios*.
